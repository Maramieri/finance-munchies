# Finance Munchies · Giochi

La pagina dei giochi del settimanale *Finance Munchies*: cruciverba, quiz e vero o falso di ogni numero, con il punteggio in percentuale calcolato in automatico.

Sito: https://maramieri.github.io/finance-munchies/

- `index.html` – la pagina (nessuna libreria esterna, solo Google Fonts)
- `giochi/index.json` – elenco dei numeri usciti
- `giochi/nN.json` – i giochi del numero N (generati dallo script di build del settimanale)

Non costituisce consulenza finanziaria.
